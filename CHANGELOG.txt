SPARTAN Version 3.11.1
======================================================================

BUG FIXES:
* autotrace: display finished message instead of "loading files" when batch processing is complete.
* batchKinetics: improve fret model filter by requiring >=5 frames for determining trace mean fret and operate over the entire trace, not just the beginning.
* batchKinetics: fixed error that prevented saving a newly created model.
* gettraces: show current laser illumination wavelength list as default value in "Change illumination metadata" context menu dialog.
* gettraces: recognize StageZ tiff metadata field and suppress warning.
* gettraces: require at least one channel to be selected in fieldArrangementDialog to avoid obscure error.
* gettraces: remove assertion to prevent loading an alignment with single color (which is ignored anyway).
* gettraces: fixed error parsing MicroManager .tif movies with one full IFD per frame.
* gettraces: only show "interleaved frames?" checkbox in field arrangement dialog when concatenated frames is selected.
* sorttraces: fixed advancing through traces does not automatically update molecule highlighted by movie viewer window.
* Enable skm and mil to be run in scripts without providing a parameter list.
* Correctly load .dwt file with unique emission models for each trace, produced by HMJP, ebFRET, etc. #27
* Check GitHub repo for latest version instead of Dropbox. #24



SPARTAN Version 3.11.0
======================================================================

NEW FEATURES:
* splittraces: a new tool for segregating traces from microarray movies.
* adecorrect: can be called with only the correction factor or no parameters.
* gettraces: support for multi-channel movies from MicroManager encoded as interleaved frames (#14).

BUG FIXES and OTHER CHANGES:
* Added GitHub and documentation PDF links to Help menus of most UIs.
* trace IDs in .traces files use movie name instead of '.rawtraces'.
* Updated 'spartan' command window, such as adding adecorrect and splittraces.
* Improve cross-platform UI consistency of font sizes and control layout (#15)
* Update new version download link to GitHub.
* Various other bugfixes.

SPARTAN Version 3.10.0
======================================================================

GETTRACES:
* Remove support for MetaMorph .stk files due to licensing concerns with tiffread.m.
* Add "subtract baseline trace" option to suppress "flagging" effect with very high FRET traces.
* Sample 10% of pixels for baseline trace to reduce computational demand.
* Apply ROI selection only after detecting overlapping molecules.

AUTOTRACE:
* Show a warning instead of an error if Curve Fitting Toolbox is unavailable when using maxTotalSigma criteria.

MAKEPLOTS:
* Add "normalize to max" contour plot option to settings dialog.

HMM:
* Deprecate support for QuB model files (.qmf) and remove source code to address licensing concerns. Will be removed completely before public release.
* dyediag: top (lines) and bottom (bars) rows have corresponding plots to avoid confusion.

OTHER:
* Movie version number from cascadeConstants.m to VERSION.txt. This solves the problem of user-modified configuration being clobbered by version updates.
* Add LICENSE.txt with copyright notices and license terms.
* Change website link for SPARTAN update dialog to the GitHub.
